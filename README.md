# VDK Arbeidsvoorwaardenplatform

Platform waarop de bedrijven van VDK Groep hun eigen arbeidsvoorwaardenpagina samenstellen:

- een afgeschermde **medewerkerspagina**;
- een vindbare **wervingspagina**;
- een **PDF met QR-code**.

Het volledige plan staat in [`docs/plan.md`](docs/plan.md). De werkafspraken voor Claude staan in [`CLAUDE.md`](CLAUDE.md).

## Werken in Codespaces

1. Klik op de groene knop **Code**, dan op het tabblad **Codespaces** en op **Create codespace**.
2. De eerste keer duurt het opstarten een paar minuten. De database, het testpostvak en alle onderdelen worden dan klaargezet.
3. Open onderin een terminal en typ `claude` om met Claude Code verder te bouwen. De eerste keer log je in via de link die verschijnt.

Een Codespace stopt vanzelf na 30 minuten zonder activiteit. Je werk blijft bewaard. Je hervat via dezelfde knop **Code → Codespaces**.
